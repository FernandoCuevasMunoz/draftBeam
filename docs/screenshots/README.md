# Capturas de draftBeam

Guarda aquí capturas **reales de la app** (PNG o WebP), por ejemplo:

- `plano.png`: editor de plano y cuadrícula.
- `muro-seleccionado.png`: muro resaltado y edición.
- `mediciones-ble.png`: vista de mediciones (sin identificadores personales).

Después agrega al `README.md` de la raíz, bajo «Capturas de pantalla», una referencia como:

```md
![Editor de plano de draftBeam](docs/screenshots/plano.png)
```

Recorta notificaciones, direcciones MAC y otros datos privados. No publiques los mockups de `android/Design/` como si fueran capturas de una compilación real.
